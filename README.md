# Paradise Nursery - Shopping Cart Application

## Project Overview
An e-commerce web application for a plant shop called Paradise Nursery. Users can browse houseplants, view details, add items to cart, and manage their shopping cart.

## Features
- Browse plants categorized by type (Succulents, Foliage Plants, Flowering Plants)
- View plant details with images, names, descriptions, and prices
- Add/remove items from shopping cart
- Update item quantities
- Calculate total cost dynamically
- Responsive navigation bar with cart icon showing item count

## Technologies Used
- React.js
- Redux Toolkit (state management)
- React Router DOM (navigation)
- CSS3

## Setup Instructions
1. Clone the repository
2. Run `npm install`
3. Run `npm start`
